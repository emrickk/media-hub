## 2. 「唯一主轴是质量」年检：通过，但预筛器有类别形状的漏洞

你的评分规则确实不看类别（第 1 节证明了这点：爆米花能拿五星，文艺唯美能拿两星）。但**放什么进来看**这一步，不同类别的把关水平差很多。命中率 = 你事后打到 4★ 以上的比例：

| 预筛器紧（放进来的基本都值） | 命中率 | 预筛器松（放进来一堆 3★ 以下） | 命中率 |
|---|---|---|---|
| 传记 (n=30) | 87% | 动作 (n=359) | 40% |
| 悬疑 (n=80) | 68% | 科幻 (n=198) | 45% |
| 动画 (n=211) | 67% | 奇幻 (n=146) | 45% |
| 剧情 (n=449) | 66% | 武侠 (n=15) | 33% |
| 家庭 (n=97) | 65% | 古装 (n=29) | 31% |
| | | 恐怖 (n=21) | 10% |

可执行的结论只有一条：**对动作/科幻/奇幻大片提高准入门槛**。它们靠场面预告混进来，最后大批死在 3★。恐怖片 21 部均分 2.81、命中率 10%，Q8「不要推荐恐怖片」现在有了完整的实证版本。

两个同机制的现象，按 H15 的规矩只描述预筛行为、不归因国籍：**国产片是你最松的准入口**（n=120，均分 3.06，命中 44%；院线档期片和社交观影都从这里进来），日影是最紧的（n=75，命中 73%，只有口碑沉淀过的才进得来）。年代同理：2010 前的电影均分 3.7 到 4.1（只看经典，幸存者偏差），2010 年代 3.30（上映季随缘看）。

另外剧集整体命中率高于电影（各时代均分 3.9 至 4.1 vs 3.3 至 3.7）：一季几十小时的承诺让你天然筛得更狠。预筛器最好的样子其实你已经在剧集上实现了。

## 方法论与局限

- **数据源**：media.db（canonical，只读），工作集取自 Emrick-clean/all_clean.json（2026-07-28 晚重建）。清洗集电影比 DB 多 2 行，为已知的双 id 合并版本（泰坦尼克 2D/3D 类），已核对。
- **样本**：豆瓣源已看已评分电影 1,066 + 剧集 486 季（245 部剧）；愿望单 86。星级按 1-5★ × 2 换算到 0-10 与大众对齐。
- **大众分 = TMDB vote_average**，2026-07-28 拉取，原始快照存 `media-hub/sources/raw/tmdb/tmdb_ratings_2026-07-28.jsonl`（1,263 条成功，1 条 404：风味人间的 tmdb id 已失效）。对比池限票数 ≥100，n=1,006；下限换 50 或 300 结论不变。TMDB 是国际观众，不是豆瓣人群；小票数条目（如陈情令 174 票）已随表标注票数供打折。
- **剧集口径**：你的分按季，大众分只有剧级，故用你各季均分对剧级分，一部剧记一次（192 部可比）。
- **124 行评分记录无 TMDB id**（8%，绝大多数为中文独占内容），按项目规约记为 documented negative，仅从大众对比中排除，其余分析全量参与。
- **2011-2015 老分**按 Q3 打折：表内标 [老分]，第 5 节处方的证据一律只引 2017 年后的分。
- 类别命中率的分母是「你放进来看过的」，不是「该类别的全部好片」，所以它度量的是预筛器，不是类别本身的产出质量。
